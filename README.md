# Problem Solving

Collection of standalone C++ practice solutions for introductory algorithm problems, including array sums, triplet comparisons, min/max sums, and time conversion.

## Getting started

Compile a single source file at a time, for example `g++ -std=c++11 simpleArraySum.cpp -o solution`, then run it with that challenge's input.
